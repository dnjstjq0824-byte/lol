# Champion Catalog, Tier List, Builds, Runes, Items, Counters & Synergy API Specification
**Document ID:** `BN-RIFTSTATS-API-CHAMPION`  

Covers API Groups 8 through 15, 17, and 18. All responses include `sampleSize`, `sampleQuality` (`HIGH_CONFIDENCE`, `MODERATE`, `LOW_SAMPLE`, `INSUFFICIENT_DATA`), `patchVersion`, `tierBracket`, and `lastUpdatedAt`. Strictly strips Arena Augment and Arena Item win rates on `queueId IN (1700, 1710)`.
